# Security policy

This policy applies to every Steelreed repository that does not have its own `SECURITY.md`.

**Please do not report vulnerabilities in public issues, discussions or pull requests.**

## How to report

1. Open the affected repository on GitHub and choose **Security → Report a vulnerability**.
2. If you cannot use GitHub, email **security@steelreed.com**.

Include the affected project and version, the steps to reproduce, and what an attacker could reach.

## What to expect

- We aim to acknowledge every report within 3 business days.
- We keep you updated until the issue is resolved.
- We credit reporters in the release notes, unless you prefer to stay anonymous.

## Supported versions

Security fixes go into the latest release of each project, unless the project's own policy says otherwise.
