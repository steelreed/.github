# steelreed/.github

Organization-wide defaults for [Steelreed](https://github.com/steelreed):

- `profile/README.md` is the organization's public profile page.
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md` and the templates in `.github/`
  apply to every repository that does not define its own.
