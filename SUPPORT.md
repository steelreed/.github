# Getting help

- **Questions and ideas:** use GitHub Discussions in the project's repository if it is enabled, otherwise open an issue.
- **Bugs:** open an issue with the bug report template. A minimal reproduction gets the fastest answer.
- **Security vulnerabilities:** report privately, as described in the [security policy](https://github.com/steelreed/.github/blob/main/SECURITY.md).
- **Business enquiries:** hello@steelreed.com
